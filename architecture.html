Factory Inventory Management — System Architecture

Vue 3 + FastAPI full-stack demo with in-memory mock data  |  Generated 2026-03-23

Tech Stack
Frontend

Vue 3

localhost:3000
  • Composition API + setup()
  • Vue Router (6 routes)
  • Vite dev server
  • Axios HTTP client
  • Custom CSS (no UI framework)
  • i18n: English / Japanese
Backend

Python FastAPI

localhost:8001
  • Uvicorn ASGI server
  • Pydantic v2 validation
  • 24 REST endpoints
  • CORS open (dev mode)
  • Python 3.11+
  • uv package manager
Data Layer

JSON / In-Memory

No database
  • 7 JSON files in server/data/
  • Loaded at server startup
  • Filtered in Python at runtime
  • Changes reset on restart
  • 3 warehouses (SF, London, Tokyo)
  • 5 product categories
